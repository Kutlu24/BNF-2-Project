# Journal d'analyse de source: modèle

Le journal d'analyse documente **une source**, et non votre usage de l'IA. Vous consignez votre usage de l'IA séparément dans le journal d'IA. Créez un fichier par source. C'est le standard minimal de l'exercice Critique des sources.
