# Mise en page du prompt: modèle

Transmettez la source à l'IA comme fichier. N'utilisez cette mise en page que si l'outil n'a pas d'accès fiable aux fichiers. Séparez visiblement les parties, par exemple avec trois guillemets.

```
"""
TEXTE DU DOCUMENT (extrait ou texte entier)
"""

"""
MÉTADONNÉES (titre, date, lieu, auteur, édition ou URL, cote d'archive, date de consultation)
"""

TÂCHE
```

## Liste de contrôle avant l'envoi

- [ ] J'ai le droit de transmettre ce matériel à l'outil (voir «Préparer votre espace de travail»).
- [ ] Texte du document et métadonnées sont séparés.
- [ ] La tâche indique le format de sortie et la langue de réponse.
- [ ] Le prompt exige que les énoncés extérieurs au matériel soient marqués comme hypothèses.
