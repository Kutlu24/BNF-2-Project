# KI-Protokoll: Vorlage für einen Eintrag

Kopieren Sie die Tabelle für jeden Eintrag neu und füllen Sie sie direkt nach dem Arbeitsschritt aus. Führen Sie **eine Datei für den ganzen Kurs** und einen Abschnitt pro Übung (zum Beispiel `## Quellenkritik`).

- **Prompt:** wörtlich. Ist er sehr lang, kopieren Sie den Kernausschnitt und kürzen Sie mit `[…]`.
- **Antwort:** zwei bis drei Sätze. Kopieren Sie eine Stelle nur wörtlich, wenn Sie sie in Ihren Text übernehmen oder einen Fehler belegen wollen.
- Die Felder von «Werkzeug» bis «Datei hochgeladen» bleiben innerhalb einer Sitzung gleich. Füllen Sie sie einmal pro Sitzung aus, nicht pro Eintrag, wenn sich nichts ändert.
