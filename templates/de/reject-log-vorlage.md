# Reject-Log: Vorlage

Ein Reject-Log hält fest, welche Treffer Sie **verworfen** haben und warum, vor allem die Treffer, die plausibel aussahen. So wird Ihre Auswahl nachvollziehbar. Führen Sie es als Abschnitt Ihres Rechercheprotokolls. Die Literaturrecherche verlangt mindestens 5 Einträge. Schreiben Sie jeden Eintrag direkt nach der Entscheidung.

**Übung:** [Name]
**Arbeitsfrage:** [Ihre Frage]

## Verworfene Treffer

## Ablehnungsgründe (verwenden Sie diese Bezeichnungen)

- **falscher Zeitraum:** Die Arbeit behandelt eine andere Zeit als Ihre Frage.
- **falsche Arena:** Die Arbeit behandelt ein anderes Land, eine andere Institution oder ein anderes Thema.
- **nur populärwissenschaftlich:** Keine Belege, keine Methode, keine Möglichkeit, die Aussagen zu prüfen.
- **nicht prüfbar:** Sie fanden keine Spur in einem Katalog, bei einem DOI oder auf der Verlagsseite.
- **erfundene Referenz:** Eine KI-Antwort nannte eine Referenz, die es nicht gibt. Notieren Sie den KI-Protokoll-Eintrag.
- **Sprache oder Zugang:** Sie können die Arbeit in der verfügbaren Zeit nicht lesen oder beschaffen.

## Auswertung

- Welche Muster sehen Sie in Ihren Ablehnungen? [zum Beispiel: viele KI-Referenzen waren nicht prüfbar]
- Welcher Suchbegriff erzeugte die meisten verworfenen Treffer? [Begriff]
