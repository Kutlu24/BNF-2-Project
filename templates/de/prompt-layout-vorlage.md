# Prompt-Layout: Vorlage

Übergeben Sie die Quelle der KI als Datei. Nutzen Sie dieses Layout nur, wenn das Werkzeug keinen verlässlichen Dateizugriff hat. Grenzen Sie die Teile sichtbar ab, zum Beispiel mit drei Anführungszeichen.

```
"""
DOKUMENTTEXT (Auszug oder ganzer Text)
"""

"""
METADATEN (Titel, Datum, Ort, Autor, Edition oder URL, Archivsignatur, Zugriffsdatum)
"""

AUFGABE
```

## Checkliste vor dem Absenden

- [ ] Ich darf dieses Material an das Werkzeug weitergeben (siehe «Arbeitsbereich einrichten»).
- [ ] Dokumenttext und Metadaten sind getrennt.
- [ ] Die Aufgabe nennt das Ausgabeformat und die Antwortsprache.
- [ ] Der Prompt verlangt, dass Aussagen ausserhalb des Materials als Annahmen markiert werden.
