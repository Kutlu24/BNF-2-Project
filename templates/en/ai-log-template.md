# AI log: entry template

Copy the table below for every entry and fill it in right after the work step. Keep **one file for the whole course** and one section per exercise (for example `## Source Criticism`).

- **Prompt:** verbatim. If it is very long, copy the core part and shorten with `[…]`.
- **Answer:** two to three sentences. Copy a passage verbatim only if you take it into your text or if you want to prove an error.
- The fields from "Tool" to "File uploaded" stay the same within one session. Fill them in once per session, not per entry, if nothing changes.
