# Prompt layout: template

Hand the source to the AI as a file. Use this layout only if the tool has no reliable file access. Separate the parts visibly, for example with three quotation marks.

```
"""
DOCUMENT TEXT (excerpt or full text)
"""

"""
METADATA (title, date, place, author, edition or URL, archive reference, access date)
"""

TASK
```

## Checklist before you send

- [ ] I am allowed to pass this material to the tool (see "Set up your workspace").
- [ ] Document text and metadata are separated.
- [ ] The task states the output format and the language of the answer.
- [ ] The prompt says that statements outside the material must be marked as assumptions.
